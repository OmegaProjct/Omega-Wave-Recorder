# Changelog

Alle nennenswerten Änderungen an diesem Projekt werden in dieser Datei dokumentiert.

## [0.1.0] - 2026-10-17

### Added
- Initiales Release von Omega Wave Recorder (Omega Media Core).
- Schlanker Multi-Track Audio Recorder mit bis zu 4 Spuren.
- OBS-Studio-Methode für isoliertes Programm-Audio (WASAPI Process Loopback für Spotify, Discord, Games).
- Hardware- und Virtuelle Audio-Eingänge (Mikrofone, Line-In, GoXLR, Voicemeeter, Stereo Mix).
- Dynamisches Audioausgangs-Routing (Systemstandard oder dediziertes Endgerät via Web Audio).
- Time Ruler & Smart-Cutting (Ripple Cut mit Micro-Fade, Davor löschen, Danach löschen).
- Hybrid-Ansicht: Kompakte 4-Spur-Stapelung umschaltbar auf klassische Retro-Einzelspur-Fokusansicht.
- Vollwertiger ID3v2-Tag-Editor für MP3/OGG/WAV-Exporte mit Cover-Art-Einbettung.
- Vollständige Projektkompatibilität: `.owrp` direkt im Omega Wave Editor (`.owep`) zu öffnen.
- Komplettes Hilfemenü (Benutzerhandbuch, Changelog, Update-Downloader, Logs, Feedback, Nachrichtencenter, Über das Programm, Projekt unterstützen).
